# Plateforme-de-Gestion-Scolaire-Inspir-e-d-Omnivox
Développée en C# avec ADO.NET, cette application web reproduit les fonctionnalités essentielles d'une plateforme scolaire comme Omnivox. Elle permet aux étudiants, enseignants et administrateurs de gérer efficacement les informations académiques et administratives.
